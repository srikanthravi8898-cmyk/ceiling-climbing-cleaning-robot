# Hardware Components List

## 1. Motor and Suction System

- **BLDC Motor:** RS2205 2300KV
  - Purpose: Drives the suction fan or impeller.
- **ESC:** Compatible with the RS2205 motor
  - Purpose: Controls motor speed.
- **Propeller / Impeller:** To be finalized
  - Purpose: Generates airflow for suction.
- **Motor Mount:** To be designed
  - Purpose: Supports the BLDC motor.

## 2. Power Supply

- **LiPo Battery:** 3S, nominal 11.1V
  - Purpose: Supplies power to the motor system.
- **Battery Connector:** Compatible with battery and ESC
  - Purpose: Provides electrical connection.
- **Power Distribution:** To be designed
  - Purpose: Distributes power to the subsystems.

## 3. Control System

- **Microcontroller:** To be finalized
  - Purpose: Controls the robot.
- **Motor Control Signal:** PWM signal to ESC
  - Purpose: Sets motor speed.
- **Sensors:** To be finalized
  - Purpose: Support monitoring and navigation.

## 4. Mechanical Structure

- **Robot Chassis:** Lightweight design
  - Purpose: Supports all components.
- **Cleaning Mechanism:** To be designed
  - Purpose: Removes dust from the ceiling.
- **Safety Tether:** Suitable load rating
  - Purpose: Helps prevent falls during testing.

## Notes

- Specifications marked "To be finalized" are still under consideration.
- Verify motor current, ESC ratings, battery discharge capability, and impeller compatibility before assembly.
- Test the suction system on a secured test rig before attempting ceiling climbing.

## Project Status

Hardware selection and prototyping in progress.
